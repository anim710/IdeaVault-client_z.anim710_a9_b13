# 💡 IdeaVault

**Live Site:** [https://ideavault.vercel.app](https://idea-vault-client-z-anim710-a9-b13.vercel.app/)

A community platform to share, explore, and validate startup ideas.

## Features

- 🔐 Secure JWT authentication with email/password login and Google sign-in support
- 💡 Post startup ideas with title, category, problem, solution, budget, tags, and image
- 💬 Full comment system — add, edit, and delete your own comments on any idea
- 🔍 Search ideas by title and filter by category with a live results count
- 🌙 Dark and light mode toggle that persists across sessions using localStorage
